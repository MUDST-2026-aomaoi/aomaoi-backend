# เช็กชื่อคนงาน (มา / ลา / ขาด)

Admin บันทึกการเข้างานรายวันของคนงานในฟาร์มตัวเอง (SuperAdmin ทุกฟาร์ม) คนงานไม่ต้องบันทึกอะไร การลาใช้วิธีโทรบอก Admin แล้ว Admin กดลา พร้อมหมายเหตุสั้นๆ

## ข้อมูล
- ตาราง `attendance` : 1 คนงาน 1 วัน 1 แถว (`UNIQUE worker_id + attendance_date`) สถานะ `PRESENT | LEAVE | ABSENT` + `note` + `auto_recorded` + `recorded_by`
- "ยังไม่ได้เช็ก" = ไม่มีแถว (ต่างจาก ขาด)
- ทุกการแก้บันทึกใน audit log (`ATTENDANCE_SET`, `ATTENDANCE_BULK_PRESENT`, `ATTENDANCE_CLOSE_DAY`)

## กติกา
- **วันเริ่มที่ 00:00 ตามเวลา `Asia/Bangkok`** (ไม่ใช่เวลาเซิร์ฟเวอร์) ใช้กับทุกที่ที่ประทับวันที่: วันเริ่มงาน, เช็กชื่อ, บันทึกงาน, dashboard
- **วันนี้เช็ก/แก้/ล้างได้จนถึง 18:00** (`ATTENDANCE_CLOSING_TIME`) หลัง 18:00 วันนี้ถูกล็อก ระบบปิดวันบันทึกคนที่ยังไม่ได้เช็กให้ (ต้องเปิด `ATTENDANCE_CLOSE_DAY_ENABLED=true`) ถ้าไม่เปิดงานปิดวัน หลัง 18:00 คนที่ยังไม่ได้เช็กจะค้างเป็น "ยังไม่ได้เช็ก" และแก้ไม่ได้
- **วันข้างหน้าบันทึกได้เฉพาะ "ลา"** (แจ้งล่วงหน้า) และยกเลิกลาได้ ผ่านปฏิทินในหน้ารายละเอียดคนงาน (ทำได้แม้หลัง 18:00) **วันที่ผ่านมาแล้วแก้ไม่ได้** "ทุกคนมา" ทำได้เฉพาะวันนี้ก่อน 18:00
- เช็กก่อนวันที่คนงานเริ่มงาน (`joinedDate`) ไม่ได้ และเช็กคนงาน `inactive` ไม่ได้
- ลาไม่แยกประเภท ไม่มีครึ่งวัน ไม่กระทบค่าแรง (ค่าแรงคิดต่อบันทึกงาน)

## API (ADMIN / SUPERADMIN เท่านั้น; Admin ถูกจำกัดที่ฟาร์มตัวเองเสมอ)
| | |
|---|---|
| `GET /api/attendance?date=YYYY-MM-DD[&farmId=]` | แถวที่บันทึกแล้วของวันนั้น (`farmId` ใช้เฉพาะ SuperAdmin) |
| `PUT /api/attendance` `{workerId,date,status,note}` | ตั้ง/เปลี่ยน; `status: null` = ล้าง (`date` ต้องเป็นวันนี้ก่อน 18:00 หรืออนาคต; อนาคตรับแค่ `LEAVE`) |
| `POST /api/attendance/bulk-present` `{date[,farmId]}` | "ทุกคนมา" เฉพาะคนที่ยังไม่ได้เช็ก (`date` ต้องเป็นวันนี้) |
| `GET /api/attendance/worker/{id}?month=YYYY-MM` | ประวัติรายเดือนของคนงาน (ปฏิทินหน้ารายละเอียด) |

## ปิดวัน 18:00 (`AttendanceCloseDayService`)
ทำงานจาก scheduler เดียวกับอีเมล (cron `0 0/15 18-20 * * *`, เวลาไทย) และเปิดด้วย `ATTENDANCE_CLOSE_DAY_ENABLED=true`:
- คนที่ยังไม่ได้เช็ก **และมีบันทึกงานครอบคลุมวันนั้น = มา**, ที่เหลือ = **ขาด** (`auto_recorded = true`, `recorded_by = system`) หลังปิดวันแก้ไม่ได้แล้ว
- **วันหยุด**: ฟาร์มที่ไม่มีแถวเช็กชื่อ (ไม่นับ "ลา" ที่แจ้งไว้ล่วงหน้า) และไม่มีบันทึกงานเลยในวันนั้น จะไม่ถูกปิดวัน (ไม่เพิ่มแถว ไม่ส่งอีเมล) ลาล่วงหน้าอย่างเดียวจึงไม่ทำให้ทั้งฟาร์มโดนนับขาด
- ข้ามคนงานที่ `inactive` และคนที่ยังไม่เริ่มงานในวันนั้น
- ทำซ้ำได้ปลอดภัย (`INSERT ... ON CONFLICT DO NOTHING`) จึงรองรับหลาย replica และรอบ retry
- ข้ามคนงานของ E2E run (`e2e_run_id`) เพราะ trigger ของ E2E ไม่อนุญาตให้เขียนนอก run
- metric `aomaoi.attendance.close_day{outcome=closed|nothing|failed}`

## ทดสอบ/สาธิต
`POST /api/test-support/attendance/close-day?farmId=<id>&date=YYYY-MM-DD` ด้วย header `X-E2E-Support-Key` ปิดวันของฟาร์มเดียวทันที
